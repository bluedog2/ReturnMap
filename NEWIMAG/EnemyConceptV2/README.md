## 진영 색

독성 초록 + 보라, 차콜 외곽과 회색 금속. 대표 강조색은 초록 `#B8D849`, 보라 `#8050AD`.
추가색은 초록 5색·보라 4색, 총 9색이다. 개별 컨셉은 기본 팔레트의 중성색 11색과 추가색 9색으로 구성한 20색 후보 안에서만 매핑했다. 디더링은 사용하지 않았다.
주인공의 크림슨·아이보리와 구별되며, 해골/임프의 밝은 머리는 보라색 장비와 초록 눈을 함께 보아 구분해야 한다. 비교판의 주인공·타일·라벨 색은 적 단일 이미지의 20색 제한과 별도다.

## 참조와 제작 과정

직접 열어 확인한 원본:

- `NEWIMAG/StyleRef/ref_concept.webp`, `ref_pixelstyle.webp`, `ref_logo.png`
- `NEWIMAG/Px32HeroV2/_1x/Hero_Idle.png`의 첫 96×96 프레임
- `NEWIMAG/GraffitiTilesFinal/Tiles/Tile_Play_Floor_A.png` (`_1x/`가 없어 지정 대체 경로 사용)
- `Assets/_Project/ResourcceEX/Sprites/Px32/Enemies/<종>_Idle.png` 5종 (역할·구 실루엣 확인용)
- `docs/hero-b-scale-impact.md` 3.4 및 `NEWIMAG/palette_v2.txt`

모든 생성 요청에 주인공 첫 프레임을 참조 입력으로 넣었다. 후기 재시도에는 동일 프레임을 최근접 8배 확대한 참조도 함께 넣었다. 목표 논리 셀 64/96/128px, k=8 또는 16 정수 블록, 1px 차콜 외곽, 2~3단 평면 음영, 오른쪽 방향, 투명 배경을 처음부터 요청했다. 전체 실제 프롬프트는 `Sources/generation_manifest.json`에 있다.

코드로 캐릭터의 선·도형·장비를 그리지 않았다. 후처리는 알파 경계 측정, 불투명 실루엣 영역 중앙 샘플링, 지정 높이 배치, 제한 팔레트 최근접 매핑, 알파 이진화, 원본 타일·주인공과의 합성이다. 라벨·눈금은 비교판의 측정용 문자다. 별도 패키지 설치 시도는 네트워크 제한으로 실패하여 Windows System.Drawing으로 처리했다. 설치 파일/작업용 임시 디렉터리는 남기지 않았다.

## 검증 결과와 한계

**최종 파일 규격 검증 통과:** 5종 셀·키 일치, 알파 0/255, 불투명 색 수 20 이하, 기본+추가 팔레트 외 색 없음, 지상 4종 발바닥이 셀 마지막 행, 임프 불투명 범위 y=10..53으로 수직 중앙. 6배 파일은 원본의 정확한 정수 최근접 확대, 비교판은 정확한 3배 확대다. `Sources/verification.txt`, `validation.csv` 참조.

**원본 격자 조건은 완전 충족하지 못했다.** 15회 모두 요청한 512/768/1024 크기 대신 1254×1254로 반환되었고, 균일한 k×k 블록과 평면 음영이 일부 구간에서 어긋났다. 종별 최대 3회 제한까지 재생성한 뒤 중단했다. 채택 원본은 논리 픽셀 격자를 완벽히 복원한 것이 아니라, 실루엣 영역을 목표 높이의 셀로 나누어 중앙 샘플링한 승인용 근사본이다. 엄밀한 원본 격자 통과를 주장하지 않는다.

이 때문에 외곽선 두께가 전체에서 정확히 1px로 일정하지 않고, 고블린의 보드·스프레이 및 스켈레톤의 손·석궁 줄 일부가 작게 뭉치거나 끊겨 보인다. 음영도 부위마다 정확히 2~3단이라고 보증하지 않는다. 오크의 굵은 파이프는 총신처럼 읽힐 여지가 있어 근접 무기 동작에서 확인이 필요하다. 이 파일은 디자인·진영 색·체급 승인용이며 최종 애니메이션 제작 전 픽셀 클러스터 정리가 필요하다.

실제 게임 장면·충돌체·AI·애니메이션 연결은 변경하지 않았다. 화면은 지정 크기의 정적인 가독성 비교용 합성이다. 저장소 쓰기는 `NEWIMAG/EnemyConceptV2/`에만 했고, git 명령은 사용하지 않았다. image_gen 원본은 도구 기본 `$CODEX_HOME/generated_images/`에 남아 있다.

## 재현

저장소 루트의 PowerShell에서:

```powershell
& NEWIMAG/EnemyConceptV2/Sources/build.ps1
& NEWIMAG/EnemyConceptV2/Sources/verify.ps1
```

두 스크립트는 현재 채택 원본으로 이 폴더 아래 결과만 다시 작성한다. 그림을 새로 생성하거나 다른 저장소 파일을 수정하지 않는다.
