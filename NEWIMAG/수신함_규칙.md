# NEWIMAG 수신함 규칙

GPT(ChatGPT 이미지 생성)가 만든 리소스를 받는 곳입니다. **Assets 밖**에 있어서 Unity는 이 폴더를 임포트하지 않습니다.
게임에서 쓰는 이미지는 언제나 `Assets/_Project/ResourcceEX/`에만 둡니다. 이 폴더의 이미지는 Claude가 그쪽으로 복사한 뒤에 씁니다.

## 1. 넣는 사람(GPT/사용자)이 지킬 것

- **묶음 하나에 폴더 하나**: `NEWIMAG/<묶음이름>/`. 묶음 이름은 영문 소문자와 숫자, `_`만 씁니다(예: `boss_lich`, `trap_saw`).
- **PNG만, 투명 배경**: 한 묶음 안에서는 캔버스 크기를 통일합니다. 캐릭터는 정사각형(기존 384×384)으로 합니다.
- **파일 이름**:
  - 애니메이션 프레임: `<캐릭터>/<상태>_00.png`, `_01` … 0부터 두 자리 번호
  - 함정 부품: `<함정>/<상태>/<부품>.png` (상태는 `Normal` / `Dud` / `Critical` / `Beneficial`)
  - 상태 이름은 코드와 맞춥니다: Idle, Run, Jump_Start, Jump_Loop, Land, Dash, Hit(주인공은 Lord_Hit에 연결), Death
- **애니메이션이 있으면 `manifest.json`을 같이 넣습니다**(아래 형식). 없으면 이미지만 복사되고 클립은 만들어지지 않습니다.
- **오른쪽을 보도록** 그립니다(왼쪽은 게임에서 flipX로 뒤집음). 발이 캔버스 아래에서 1/8 높이에 오게 맞춥니다(피벗 0.5, 0.125).
- 생성 프롬프트는 `generation.json`에 남겨 두면 다음 생성 때 톤을 맞추기 쉽습니다.
- **`.meta` 파일은 넣지 않습니다.** 넣어도 복사되지 않습니다.

### manifest.json 형식 (v2)

```json
{
  "version": 2,
  "pixelsPerUnit": 256,
  "pivot": [0.5, 0.125],
  "characters": [
    {
      "id": "boss_lich",
      "animations": [
        { "state": "Idle", "fps": 6, "loop": true,
          "frames": ["boss_lich/Idle_00.png", "boss_lich/Idle_01.png"] },
        { "state": "Death", "fps": 12, "loop": false,
          "frames": ["boss_lich/Death_00.png", "boss_lich/Death_01.png"] }
      ]
    }
  ]
}
```

- `frames` 경로는 manifest가 있는 폴더를 기준으로 합니다.
- `pixelsPerUnit`과 `pivot`은 생략할 수 있습니다(기본값 256, [0.5, 0.125]).
- 권장 FPS는 대기 6, 달리기 12, 대시 16, 피격·사망 12입니다. 피격·사망·착지는 `loop: false`로 둡니다.

## 2. 넣은 뒤 Claude에게 말하기

"NEWIMAG/<묶음이름> 넣었어"와 함께 **어디에 쓸지**를 알려주세요.
예: "보스 몬스터로 써줘", "스파이크 함정 비주얼 교체해줘"

## 3. 가져오기 절차 (Claude가 하는 일)

1. 묶음을 확인합니다: 파일 이름 규칙, 투명 배경, 캔버스 크기 통일, manifest의 frames가 실제 파일과 맞는지
2. **가져오기**: Unity 메뉴 `ReTrap → Art → NEWIMAG 수신함 가져오기`를 쓰거나, Unity MCP로
   `ReTrap.EditorTools.ArtInboxImporter.Import("<묶음이름>", "Assets/_Project/ResourcceEX/Sprites/<분류>/<묶음이름>")`를 호출합니다.
   - PNG만 복사합니다(새 GUID). 하위 폴더 구조는 그대로 유지합니다.
   - **같은 이름의 파일이 있으면 건너뜁니다.** 기존 참조를 보호하려는 것이고, 교체는 따로 판단해서 합니다.
   - 임포트 설정: Sprite(Single), Point 필터, 무압축, 밉맵 끔, PPU와 피벗은 manifest 값(없으면 기본값)
   - manifest가 있으면 `<대상>/<캐릭터id>/<상태>.anim` 클립을 만듭니다(이미 있으면 건너뜀).
3. 배선: 프리팹의 SpriteRenderer는 **Map 소팅 레이어**에 order를 맞추고(캐릭터 20, 함정 10 등), Animator 상태에 클립을 연결합니다.
   함정은 `TrapPrefabBuilder` 흐름을 따릅니다.
4. 검증: `tools\ci\unity-ci.ps1`(컴파일·소팅 레이어 검사)를 돌리고, 사람이 플레이로 크기·흔들림·타이밍을 확인합니다.
5. 다 가져온 묶음은 NEWIMAG에 그대로 남겨 원본 보관용으로 씁니다.

## 기존 묶음

`AnimationV2`(추천, 8프레임), `Traps`, `Effects`, `Tiles`, `Replacement`(4프레임 호환본), 그리고 루트의 4프레임 초기본이 있습니다. 자세한 내용은 `README.md`와 `새버전_사용법.md`를 보세요.
이 폴더가 Assets 밖으로 옮겨지면서 `.meta`는 지웠습니다. 그 문서에 나오는 ".meta 포함" 설명은 이제 가져오기 도구의 임포트 설정이 대신합니다.
