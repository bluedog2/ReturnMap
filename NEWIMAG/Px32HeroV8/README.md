## 손과 가방

장갑 의미 영역은 x=60..64, y=82..85입니다. 검은 외곽과 주먹/손등 형태를 유지하고, 밝은 강조점은 (62,83)의 1px입니다. 손 바로 아래의 벨트 행은 y=86이며, 손끝이 몸 실루엣 안쪽에 닿습니다. 소매보다 작은 손과 대각선 손목 연결을 3배 및 8배 정지 확대에서 확인했습니다. 어깨를 올리지 않고 팔꿈치가 아래·왼쪽으로 빠지며, 팔과 몸통 사이에 작은 빈틈이 있습니다. 손의 자연스러움 판정은 육안 판정이며 수치 검사와 별개입니다.

가방 몸체는 (51,88)에 배치한 19×15px입니다. 원본 가방 확대 참조를 사용해 별도로 생성한 검은 몸체·빨간 띠·리벳·위아래 송곳니 디자인입니다. 생성된 고리 왼쪽 부분 3×3px를 잘라 (67,85)에 평행이동했습니다. 벨트 아래 몸체 윗변 거리는 2px이고, 손 ROI와 몸체·고리의 불투명 픽셀 사이 최소 빈 간격은 체비쇼프 거리 기준 2px입니다. 가방은 무릎 위에서 끝나며 팔꿈치 빈틈을 덮지 않습니다.

## 합성과 전환

- `Sources/C1_generated.png`에서 C 팔과 가방 제거 후 드러나는 부분을 복원했습니다. 손은 `C4_generated.png`의 4×4 블록 패치를 손등 안쪽에 합성했습니다. C2는 위치가 달라지고 강조점이 남아 제외, C3는 폭이 커서 제외했습니다.
- 두 안은 같은 완성 C 패치를 공유합니다. 1안에만 공통 가방 레이어를 덧붙였습니다. Idle은 각 원본 프레임에 이 패치를 정수 이동 (0,0)으로 재사용합니다. 허리 기준점을 고정했으며 마스크 밖 원본 호흡은 그대로입니다. 프레임별 재생성은 없습니다.
- 원래 소매·가방·손목, 새 팔 자리, 가방이 가렸던 반바지·허벅지와 1안 가방 자리만 편집 마스크에 포함했습니다. 머리·얼굴·머리카락·몸통 위쪽·신발은 원본 픽셀입니다. 정지 확대에서 원래 가방과 팔 조각이 남지 않는지 확인했습니다.
- BagStow 1번째는 원본 Idle0 그대로, 2·3번째 팔만 별도 생성 부분을 합성, 4번째는 2안 마스터 그대로입니다. 원본 가방 레이어의 이동은 2번째 (-8,-9), 3번째 (0,-31)입니다. 2번째에서 왼쪽으로 넘기고 3번째에서 뒤쪽 위로 들어가 캐릭터의 몸/머리카락 실루엣에 가려집니다. 가방은 회전·재생성 없이 같은 픽셀을 이동했으며 노출 픽셀은 각각 196, 0입니다.
- 생성 결과는 근사 격자이므로 고정 정수 간격의 블록 표본을 읽었습니다: 캐릭터 10px, 가방 46px, 장갑 78px. 목표 크기에 맞춘 리사이즈·회전이나 코드로 윤곽을 그리는 작업은 하지 않았습니다. 이후 원본 20색 팔레트 매핑·알파 128 임계값·마스크 합성만 적용했습니다. 미리보기만 최근접 정수 확대합니다.
