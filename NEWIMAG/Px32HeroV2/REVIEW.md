# Hero v2 애니메이션 납품 기록

모든 산출물은 이 디렉터리 아래에만 저장했다. git 및 Assets 수정 없음.
생성: 내장 image_gen. 원본은 Sources, 전체 프롬프트는 attempts.json.
Idle은 승인된 Hero_B 원본 픽셀 영역의 평행이동만 사용했다(생성 호출 0회).

## 파일
- `_1x/Hero_{Idle,Run,JumpStart,Fall,Land,Dash,Hit,Death}.png`: 96×96 셀, 가로 한 줄.
- `Player/Hero_*.png`: 위 시트의 정확한 최근접 8배. 가져오기 대상.
- `Animations/Hero_*_3x.apng`: 정확한 최근접 3배. fps 순서 8/12/12/8/12/20/10/10.
- `Sources/Hero_*_attempt*.png`: 채택 및 비교용 생성 원본. 채택 번호는 attempts.json.
- `Sources/Hero_Idle_approved_reference.png`: Idle에 사용한 승인 원본 복사본.
- `Preview_3x.png`: Idle, Run, JumpStart, Fall, Land, Dash, Hit, Death 순. 각 행 왼쪽 첫 그림은 Hero_B.
- `attempts.json`, `validation.json`: 프롬프트·시도 내역 및 프레임별 검사.
- `build.py`, `verify_exports.py`: 재현용 복원 및 산출물 검증 스크립트. 외부 라이브러리 없음.

## 디자인 및 규격 한계 — 자동 검사 통과와 별개
- **완전한 디자인 일치 또는 사람의 최종 승인을 주장하지 않는다.** 큰 디자인 요소(아이보리 포니테일, 머리 장식, 크림슨/차콜 의상, 비대칭 양말, 이빨 상자)는 유지되지만 생성 프레임은 원본 픽셀의 정확한 복제가 아니다.
- 프레임 번호는 아래에서 **1부터** 센다. Run 4/5/8의 상자 각도·이빨 수·윤곽 및 양말/다리 가림이 달라 보인다. Run 전체에서 얼굴·머리카락 내부 클러스터가 조금씩 변한다.
- JumpStart 2, Fall 1–2는 눈·입과 머리 실루엣이 기준 그림과 다르다. Fall은 81–84px로 기준 80px보다 약간 크다.
- Land 1–3은 얼굴·재킷의 작은 픽셀 클러스터가 달라진다. 높이 편차 규칙을 위해 착지 웅크림은 얕다.
- Dash 1–4는 얼굴/상자 세부가 원본과 다르며, 높이 75–77px로 기울어진 자세를 유지한다. 잔상은 image_gen 원본에 포함된 것만 사용했다.
- Hit 1의 위로 젖힌 얼굴과 Hit 2의 찡그린 얼굴은 피격 표현이지만 기준 얼굴의 정확한 픽셀 일치는 아니다.
- Death 3–6에서 상자 무늬와 손·소매의 겹침이 달라진다. 마지막 프레임은 전신·머리카락·상자가 셀 안에 있고 누운 자세다. 첫 프레임은 85px로 기준보다 5px 크다.
- 문서 `hero-b-scale-impact.md`의 **폭 ≤56px를 모든 동작에 적용하면 미충족**이다. 폭 범위: Idle 52–53, Run 63–73, JumpStart 57–63, Fall 71–73, Land 54–56, Dash 82–91, Hit 69–77, Death 64–90. 사용자 메시지의 자동 검사 목록에는 폭 제한이 없으므로 해당 검사와 문서상 한계를 구분했다. 강제 축소/왜곡으로 맞추지 않았다.
- image_gen은 요청한 출력 치수와 엄격한 정수 블록을 정확히 지키지 않았다. 실제 크기에서 요청 셀 격자의 중앙을 샘플링하고 팔레트 최근접 정리·알파 이진화·1~2px 고립점 제거·전체 프레임 평행이동만 수행했다. 원본의 완벽한 정수 픽셀 격자 정확도는 보장하지 않는다.
- Death 1차 원본의 첫 행 발이 다음 행 경계에 걸쳐, 두 번째 행 추출 시작을 원본 좌표에서 28px 아래로 옮겼다(같은 샘플 간격, 그림 변형 없음). 이로써 이웃 프레임의 가느다란 잔여선을 제거했다.
- Idle의 상체 호흡은 기존 픽셀을 아래로 1px 이동시키고 포니테일 끝/재킷 자락은 옆으로 최대 1px 이동시켰다. 새 픽셀 도형을 그리지 않았다.

## 재현
저장소 루트에서 `python -B NEWIMAG/Px32HeroV2/build.py`, 이어서 `python -B NEWIMAG/Px32HeroV2/verify_exports.py` 실행.
검사 파일은 생성될 때 갱신된다. 스크립트는 이 디렉터리 외부에 쓰지 않는다.

- Idle 이음선 수정: 프레임 0 원본 픽셀로 재구성, 가로 컷아웃 이동 제거 및 허리 y=64 연결로 상체 0/1/1/1/0/0px 호흡 적용; 6프레임 각각 최근접 4배 육안 확인에서 세로·가로 이음선 및 고립 밝은 점 0. 20색, 알파 0/255, 바닥 95, 중심 편차 0px, 높이 편차 ±0.5px; 8배 PNG·3배 APNG 8fps·Preview 첫 줄 갱신. 기존 build.py의 Idle 생성식은 수정 전 방식이므로 전체 재실행 시 이 수정을 덮어씀.
