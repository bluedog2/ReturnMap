# Re:Trap Enemy V3

image_gen으로 새로 그린 5종 × 4애니메이션, 20시트 / 90프레임. 기존 v2 픽셀은 최종 그림에 사용하지 않고 4배 참조본으로만 사용했습니다.

## 파일

- `_1x/<종>_<애니>.png`: 1배, 가로 한 줄 시트 20장.
- `Enemies/<종>_<애니>.png`: 정확한 최근접 4배, 가져오기 대상 20장.
- `Animations/<종>_<애니>_3x.gif`: 최근접 3배 GIF 20장, 프레임당 120ms.
- `Compare_3x.png`: v2/v3 Idle 첫 프레임과 Hero V3, 32px 눈금.
- `Sources/*_attempt*.png`: image_gen 원본 22장.
- `Sources/References/*_v2_4x.png`: 승인 v2 참조본 20장.
- `Sources/*_recovery.json`: 선택 원본의 격자 복원 정보.
- `Sources/process.py`, `compare.ps1`, `finalize.py`: 후처리·검사·비교판 생성 도구.
- `attempts.json`: 전체 프롬프트, 원본 경로, 시도 및 선택 기록.
- `validation.json`: 20시트 및 프레임별 검사 수치.

## 추가 디테일

- 고블린: 후드 봉제선, 눈·이빨, 천 주름과 찢김, 벨트·장갑·금속 부품.
- 임프: 두개골 균열·이빨, 날개 뼈대와 막 음영, 꼬리 띠와 발톱.
- 스켈레톤: 두개골·치아·갈비뼈·손가락, 석궁 시위·장치, 찢어진 옷자락.
- 기사: 투구 통풍구, 판금 관절·체인, 방패 리벳·X 페인트 긁힘, 금속 하이라이트.
- 오크: 표정·엄니·손가락, 조끼 봉제선·찢김, 체인 고리, 파이프 칼라·플랜지·볼트.

## 시도 및 한계

총 image_gen 22회. 스켈레톤 Run/Death 각 2회, 나머지 18시트 각 1회. 첫 스켈레톤 Run/Death의 작은 점과 질감을 줄이기 위해 재생성했습니다.

생성 원본은 요청한 정확한 4배 블록·캔버스·균등 격자를 지키지 않았습니다. 새 원본의 투명 간격으로 프레임을 분리하고, 프레임 경계상자 기준 격자 복원과 팔레트 정리·알파 이진화·고립점 제거·평행이동을 수행했습니다. 새 얼굴이나 장비를 코드로 그리거나 기존 v2 그림을 확대하여 최종 그림으로 쓰지 않았습니다. 비교판의 글자와 눈금만 코드로 표시했습니다.

임프 Death는 중앙 기준 대신 추락 궤적과 마지막 바닥·누운 자세를 적용했습니다. 외곽선 두께와 3~4단 평면 음영은 육안 검사이며, 모든 국소 경계가 정확히 1px임을 자동 보증하지는 않습니다. 모델이 동작마다 세부 형태를 조금 바꿀 수 있습니다. 게임 엔진에서의 실제 재생·가져오기는 수행하지 않았습니다.

지정 폴더 밖 저장소 파일은 수정하지 않았고 git은 사용하지 않았습니다. image_gen 기본 원본은 허용된 CODEX_HOME에 남아 있습니다. 임시 작업 파일은 정리했습니다.
