## 제작과 색

그림은 모두 built-in **image_gen**으로 생성했다. 승인 주인공·함정 이미지를 매 호출 참조로 입력하고 논리 픽셀의 k배 블록을 요청했다. StyleRef 3장, 주인공 Idle/Dash/Hit/Death, 적 Idle 전종, 함정 States/Scene/Preview, 확정 바닥 타일, 기존 효과 16장, 규격 2.2·2.4를 열어 확인했다. 기존 효과는 역할만 참고했고 디자인은 재사용하지 않았다.

코드는 그림의 선·도형을 새로 그리지 않았다. 생성 영역 검출·선택, 영역 중앙 샘플링, 팔레트 정리, 합성, 라벨에 사용했다. 링은 생성된 상단 좌측 사분면을 반전 복사해 대칭을 보정하고, 기존 링 픽셀 영역을 45도씩 선택 합성하여 채움 단계로 구성했다. HUD 선택 칸은 단색 패널 합성이다.

**추가색 0개.** `NEWIMAG/palette_v2.txt`만 사용하며 최종 PNG는 파일별 16색 이하, 순흑 없음, 알파 0/255다. 새 개별 시트는 최대 11색이다. 초록·보라는 EnemyPoof와 이를 포함한 검토 화면에만 썼다.

- 기본: 차콜 `#19181F`, 크림슨 `#641F36 #92223F #B83450 #DC526B #F18490`, 아이보리 `#F7EEE4` 및 기존 중성색.
- 먼지: `#555058 #74666A #8D7B80 #B3A1A0 #D0BEB8`.
- 적: 승인 초록·보라 램프만 사용.
- 금: `#79502B #B67C32 #E8B94F #FFE09A` 중 샘플에 필요한 색만 사용.

비교판·플레이 목업·HUD도 전체 파일당 16색으로 정리했다. 따라서 목업 안의 승인 캐릭터·타일은 원본보다 일부 중간색이 합쳐져 보인다. 원본 파일은 수정하지 않았다. GIF는 색을 직접 인덱스로 기록하며 투명 영역은 검토용 차콜 배경으로 표시한다. **투명 원본은 PNG를 사용한다.**

## 확인한 범위와 한계

- PNG 치수·알파·팔레트·색 수, GIF 디코딩·프레임 수, Ring32 지름 14px 중앙 투명 공간을 검사했다. Sheet·Scene·HUD는 실제 출력물을 열어 확인했다.
- 생성기가 정확한 k배 격자를 그대로 지키지는 않았다. 이번 것은 생성 영역을 목표 크기로 중앙 샘플링한 컨셉이며, 원본 격자 충실도나 최종 픽셀 클러스터 품질을 인증하는 결과는 아니다. 작은 파편과 외곽선은 최종 제작 때 수작업 검토가 필요하다.
- 일부 단일 항목 원본에 여러 변형이 생성되어 승인 Normal에 가까운 대표 영역 하나를 선택했다. 선택 영역과 팔레트 처리는 `build.ps1`에 기록했다. 사망 경계와 Spike 영역은 검수 후 재조정했다.
- 4px 파티클은 원본을 3×3 중심 샘플로 정리한 뒤 4×4 투명 셀에 합성했다. 작은 점의 판독성을 우선하여 8px 버전과 픽셀 배치는 다르다.
- 효과는 원샷 애니메이션을 검토 편의상 반복한다. 마지막에서 첫 프레임으로 돌아갈 때의 점프는 원샷 재시작이다. 최종 타이밍·위치·대시 이동과의 동기화는 게임에서 확인해야 한다.
- Scene은 효과 위치·진영색·월드 UI 크기를 보는 합성 목업이다. 확정 배경 아트나 실제 게임 실행 캡처는 아니다. Unity 임포트·재생·충돌·상태 전환 검사는 수행하지 않았다.
- 최종 승인 후 셀별 작은 파편, 외곽선, 프레임 간 중심 이동 및 계단형 링 두께를 다듬는 단계가 남아 있다.
