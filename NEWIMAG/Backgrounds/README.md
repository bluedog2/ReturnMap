내장 image_gen으로 4장을 개별 생성하고 PowerShell/System.Drawing으로 후처리했다. 기준 타일 2장과 NEWIMAG/overview.png를 먼저 열어 색감과 도트 밀도를 확인했다. 사용 프롬프트, 원본 위치, 후처리 및 파일별 검사 결과는 generation.json에 기록했다.

권장 패럴랙스 계수: 원경 **0.15**, 근경 **0.45**. 원경 → 근경 → 게임 지형·캐릭터 순으로 그린다. 가로 Repeat, 세로 Clamp, Point/Nearest 필터를 사용한다. 근경 요소는 y=564~1023, 하단 약 45%에 배치했다.

## 후처리와 점검

- 모든 출력은 4×4 단색 픽셀 블록이다. 최근접 표본 추출, 채도 조정, RGB 12단위 양자화를 적용했다. 공간 블러나 안티앨리어싱은 사용하지 않았다.
- 근경의 생성 알파를 임계값 192로 이진화했다. 최종 알파는 0 또는 255이며 반투명 픽셀은 없다. 마젠타 키 변환은 필요하지 않았다.
- 양쪽 128픽셀에서 대응 색상으로 단계형 경계 보정을 했다. 4장 모두 왼쪽·오른쪽 끝 열의 RGBA가 전 행에서 동일하다(다른 행 0/1024).
- 원경 2장 전체 알파 255. 근경 2장 상단 564행의 불투명 픽셀 수 0. 크기 및 4×4 블록 균일성 검사도 모두 통과했다.
- process.ps1에 후처리와 검증 코드를 남겼다. 재생성에는 generation.json의 도구 원본 경로가 필요하다.

## 알려진 한계

- 좌우 끝 열의 완전 일치는 수치로 확인했지만, 경계 보정 구간에는 색 띠나 형태 변화가 보일 수 있다. 장시간 스크롤에서 성·나무의 반복 패턴이 드러날 수 있다.
- 수직 반복용이 아니다. 번개와 발광은 정지 이미지이며 애니메이션은 포함하지 않는다.
- 생성 원본의 미세한 명암은 4픽셀 단위 색 패턴으로 남을 수 있다. 수작업 도트 타일과 픽셀 표현이 완전히 같지는 않다.
- 엔진 내부 합성, 실제 카메라 스크롤, 캐릭터·함정 가독성은 실행 검증하지 않았다. 텍스처 필터와 카메라의 소수점 이동에 따라 화면에서 번짐이 생길 수 있다.
- 저장소에 쓴 파일은 NEWIMAG/Backgrounds/ 아래뿐이다. image_gen 자체는 기본 생성 캐시에 원본을 자동 저장한다. git 명령은 사용하지 않았다.
