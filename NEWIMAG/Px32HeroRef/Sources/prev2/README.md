## 이빨·Open·보존 검증

닫힌 가방은 기존 뚜껑 빨간 띠·손잡이·모서리 리벳을 남기고 입 영역만 합성했습니다. 허리 윗니 3개, 든 크기 윗니 4개이며 아랫니 줄은 생성 픽셀을 정수 평행이동해 엇갈리게 조립했습니다. 흰 이빨은 앞면 세로 영역 절반 이상을 차지하며 틈은 승인 팔레트의 가장 어두운 색(25,24,31), 일부 내부는 어두운 빨강입니다. Open 2종은 경첩이 이어진 열린 뚜껑·상하 이빨·내부를 다시 생성했습니다. 허리 Open 20×23, 든 Open 28×30으로 열린 뚜껑 때문에 닫힌 자산보다 큽니다.

3/4와 팔 4장 모두 **승인 Idle 0 대비 마스크 밖 RGBA 불일치 0**입니다. `Masks/Idle0_Arm_*.png`는 3/4 수정 영역과 자세 영역의 합집합입니다. 기존 `Masks/Arm_*.png`는 3/4 대비 자세 수정 영역입니다. Forward 마스크의 y88 아래는 실제 팔이 아니라 내린 팔을 지웠던 배경 복구 영역이므로, 그 영역에 새 가방을 다시 올렸습니다. 실제 뻗은 팔·장갑은 y88 위이며 픽셀 불일치 0입니다. 나머지 자세는 기존 팔 마스크 전체 불일치 0입니다.

모든 생산 PNG는 승인 팔레트 내 20색 이하, 알파 0/255입니다. 캐릭터 8장 바닥은 127입니다. 원시 image_gen PNG에는 중간 알파·많은 색이 있을 수 있으며 생산 검증 대상과 분리합니다. 검수 확대본은 정수 픽셀 반복이며 생산 이미지 리샘플이 아닙니다. 생성 격자가 정확하지 않아 복원 후 최종 픽셀을 3배·4배·8배·16배로 확인했습니다.
