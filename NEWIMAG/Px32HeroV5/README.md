## 검수 결과

- **Run**: 머리 높이 범위2px·인접 최대1px·루프1px로 떨림 수치는 개선. 그러나 0/4 접지에서 선행 다리 교대가 불명확하고 눌림·밀기 포즈 차이가 작아 요구한 좌우 4단계 달리기로 승인하지 않음.
- **Fall**: 두 장 모두 머리36·하단121행, 중심 차1px. 다리는 아래로 향하고 팔·옷자락에 작은 상향 변화가 있어 낙하 루프 연결을 통과. 머리카락은 전체 머리 고정 규칙에 따라 Idle 그대로이며 별도 휘날림 없음.
- **Land**: 머리40→32→27, 발127, 마지막 장은 Idle0과 RGBA 완전 일치. 그러나 생성 몸/상자가 Idle보다 가늘고 작아 1→2에서 어깨·상자가 갑자기 커짐. 마지막 장의 일치만으로 전체 회복 동작을 승인하지 않음.

## 처리 규칙과 한계

- 실제 Assets의 Idle0에서 V4 전체 머리 마스크(얼굴·앞머리·포니테일·머리핀)를 추출해 2180 불투명 픽셀을 합성. 저장 PNG의 모든 머리 픽셀 일치를 별도 검사. 머리 bbox 69×57. Land2는 Idle0 전체 RGBA 그대로 합성.
- 몸은 내장 image_gen만 사용. 후처리는 V4 방식의 고정 블록 중심 복원, alpha128 기준 이진화, Idle 20색 팔레트 매핑, 고립1px 정리, 정수 평행이동, 승인 픽셀 합성·조립뿐. 프레임별 리샘플·회전·변형·새 캐릭터 픽셀 그리기 없음. 3x 미리보기는 픽셀 반복 확대만 사용.
- 고정 복원 간격: Run1/2/3=5px, Fall1=10px·2=12px, Land1=6px·2/3=8px. 원본 확대 블록/외곽선 간격을 기준으로 정했으며 목표 bbox에 맞춘 프레임별 배율은 사용하지 않음. image_gen 원본은 완전한 정수 격자가 아니므로 복원은 근사이며 일부 외곽선 접합부 두께의 완벽한 1px는 보장하지 못함.
- Run3 전체 세로 이동은 접지 기준 대비 [0,0,0,-2,0,0,0,-3]px. 목표 예시 곡선과 동일하지는 않지만 접지와 공중 높이를 지키면서 머리 범위2px·인접1px·루프1px를 만족.
- 접지127행과 하단1px 투명은 서로 양립 불가하므로 V4처럼 접지 프레임의 하단만 예외. 상단/좌우1px는 모두 투명. Fall과 Run 공중 프레임 하단은 투명.
- 머리카락 휘날림/처짐은 Idle 전체 머리 고정 지시와 양립하지 않아 머리 고정을 우선. 낙하의 팔·옷자락과 착지의 몸 포즈로 동작 표현.
- Assets 및 다른 NEWIMAG 폴더는 참조로만 읽었고 git 작업은 하지 않음. Unity 가져오기·게임 플레이 검증은 이번 산출물 범위에 포함하지 않음.
