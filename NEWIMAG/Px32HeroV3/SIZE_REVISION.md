# Idle 기준 크기 재작업 — 2026-11-02

7종의 1x PNG, 4x PNG, 3x GIF를 교체했다. **엄격한 크기 조건은 미달이며 전체 검증은 실패다.** 승인된 Idle 3개 파일은 SHA-256 비교로 변경 없음이 확인됐다.

기준 첫 프레임: 전체 키 101px, 얼굴+앞머리 44×40px, 상자 23×19px, 신발 20×18px / 18×18px. 포니테일은 머리 bbox에서 제외한다. 상자 손잡이는 제외하고 신발은 상단 커프를 포함한다.

|시트|키 px|Idle 대비 키 차이|머리 폭/높이 차이 px|선택 / 총 시도|컷아웃|
|---|---|---|---|---|---|
|Run|101–104|0…+3|+2…+5 / +3…+4|1 / 4|8프레임|
|JumpStart|84, 101|−17, 0|0…+1 / 0|4 / 4|2프레임|
|Fall|99, 97|−2, −4|0 / 0|4 / 4|2프레임|
|Land|74, 93, 102|−27, −8, +1|0…+1 / 0|4 / 4|3프레임|
|Dash|94, 94, 93, 93|−7…−8|+1 / 0|4 / 4|4프레임|

|Death|102, 90, 72, 70, 44, 44|+1…−57|−7…+3 / −11…0|4 / 4|없음|

시도 횟수는 기존 크기 재작업 후보 1·2차와 이번 3·4차를 합친 값이다. 이전 V3 최초 제작 시도는 별도 이력으로 보존했다. `attempts.json`의 `size_revision`에 생성 프롬프트, 원본, 탈락 원인, 선택 후보가 있다. 도구는 built-in image_gen이며 API 우회는 쓰지 않았다.

컷아웃은 Idle 얼굴+앞머리의 불투명 픽셀만 원래 크기로 합성했다. 몸·팔·다리·상자·신발은 image_gen 출력이다. 목/포니테일 접합부를 유지하기 위해 원래 앞머리 일부가 남는다. 따라서 **컷아웃 자체 44×40px와 합성 후 머리 전체 bbox는 구별**한다. Run은 이 때문에 머리 크기 조건을 통과하지 못했다. Hit·Death는 각도/표정 차이 때문에 적용하지 않았다.

상자·신발에도 ±1px를 넘는 편차가 남았다. 가려진 신발은 null로 기록했고 통과시키지 않았다. 회전/가림이 있는 부위는 수동으로 지정한 의미 영역 내 불투명 픽셀 경계 측정이므로 완전한 의미 분할 검증은 아니다. 원본 생성 격자도 완전히 균일하지 않아 외곽선과 세부 선에 불규칙함이 남는다.

Fall 2프레임과 Hit 2프레임은 서 있는 키 조건 미달이다. Hit는 높이 드리프트 ±2px도 실패한다. JumpStart 첫 프레임, Land 착지/회복, Dash 기울기, Death 포즈는 높이 예외로 기록했다. 나머지 시트는 가져오기용 중심/높이 드리프트 조건을 만족하지만 부위 크기까지 만족했다는 의미는 아니다.

모든 새 PNG는 팔레트 20색, 알파 0/255, 금지 가장자리 불투명 0개, 바닥행 127이며 4x 출력은 정확한 최근접 복제다. 7개 GIF의 크기와 프레임 수를 재검사했다. 실루엣 확대·축소 리샘플은 하지 않았다. 허용된 고정 4px 격자 복원, 팔레트 매핑, 알파 이진화, 고립점 제거, 평행이동, 컷아웃만 사용했다.

`SizeCheck_3x.png`는 Idle과 나머지 7종 첫 프레임 및 Run 1–4프레임을 같은 바닥선에 놓고, 32px 눈금과 Idle 머리 상·하단 가이드를 표시한다. 상세 수치는 `validation.json`을 참조한다.
