## 측정과 실패 이유

- 기준: 승인 Idle0 머리 위27, 키101. 가방 제외 어깨37px, 목→벨트15px, hip-knee-ankle 경로21.03/19.44px, 신발20×16/18×16px, 가방23×17px.
- 어깨: 전체 bbox 대신 머리/가방을 제외한 상완 상단 영역의 불투명 실루엣 폭. Idle은27px, Run은24~28px로 축소가 명확합니다.
- 몸통: 수동 목/벨트 landmark y차. 다리: hip→knee→ankle 두 선분 길이. 신발: 의미 ROI 내 불투명 bbox. Run 신발 각도가 달라 projected bbox만으로 실제 크기를 정확히 입증할 수 없습니다.
- `annotations.json`에 기준/프레임별 ROI와 관절 좌표, `validation.json`에 방법·측정값·불확실성·차이를 저장했습니다. `Sources/*body_without_bag_mask.png`는 실제 사용한 가방 제외 실루엣입니다. 사각 가방 ROI를 보수적으로 제외하며 가려진 몸을 코드로 복원하지 않았습니다.
- Idle 머리 위28~31로 목표26~27 미달, 키97~100으로 호흡 폭도 초과. 승인 Idle 각 번호의 머리를 그대로 썼으며 움직임을 맞추려고 몸을 늘리지 않았습니다.
- Run 머리 위28~31, 범위3/인접2px. 검은 스타킹/맨다리가0/4에서 교대하지만 밀기·공중 연결과 팔 반대 스윙 전체는 제작 통과로 판정하지 않았습니다. 공중3/7은 바닥 기준에서4/3px 위로 평행이동했습니다.
- 가방은 왼쪽 허리 고리에 있지만 원본보다 작습니다. 이빨/외곽 모양과1~2px 지연 흔들림 조건도 통과하지 못했습니다.
- 정확한1px 외곽선은 생성 격자의 불완전성과 복원 접합 때문에 미보장입니다. 파일 형식 검사 통과와 제작 통과를 구분했습니다.

## 처리 규칙과 재현

캐릭터 새 그림은 내장 image_gen만 사용했습니다. Idle3원본의8px 블록, Run2원본의7px 블록을 시트 전체 고정 간격 중심으로 복원했습니다. 이는 원본 확대 블록의 근사 복원이며 프레임별 목표 크기에 맞춘 리샘플은 하지 않았습니다. 알파128이진화, 승인 Idle20색 최근접 매핑, 고립1px 정리, 정수 평행이동, 승인 머리 합성만 수행했습니다. 머리 마스크는V4/V5에서 사용한 전체 머리·포니테일 경계를 각 승인 Idle 번호에 적용했습니다. Idle은같은 번호, Run은0번입니다. 전체 머리 픽셀은 팔레트 정리 이후 원본 RGBA로 덮어썼습니다.

접지127행과 하단1px투명은 양립하지 않으므로 기존 기준대로 접지 하단만 예외입니다. 상단/좌우1px투명, 가로 중심±2px, 이진 알파,24색이하를 검사했습니다. 비교판 눈금은 진단용이며 시트에는 들어가지 않습니다.
