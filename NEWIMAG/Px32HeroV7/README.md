## 판정과 한계

- 14프레임 모두 마스크 밖 원본 RGBA와 불일치 0개. 20색, 알파 0/255, 불투명 바닥 행 127, 시트 규격 통과. 원본 두 파일 SHA256 변경 없음.
- 가방은 `Sources/bag_master.png` 하나(23×19)를 모든 프레임에 정수 평행이동만 적용했습니다. 저장된 개별 가방 레이어 전체 RGBA를 역이동해 일치 검증했고, 합성된 불투명 가방 픽셀도 검사했습니다. 앞선 시도의 개별 가방은 최종 공통 자산으로 선택하지 않았습니다.
- Idle 팔은 1차 후보 0프레임 패치를 고정 재사용합니다. 머리·표정 등 마스크 밖 호흡은 원본 그대로입니다. 가방 y 변화는 0~1px입니다. Run 가방 좌표는 프레임마다 최대 축별 2px 변화하며, 실제 엉덩이 대비 지연 위상은 검증 통과하지 못했습니다.
- **마스크 밖 일치만으로 해부학적 보존을 통과 처리하지 않았습니다.** 새 가방 자리 일부가 기존 다리/신발 실루엣과 겹칩니다. 따라서 “가려져 있던 부분 외 다리·신발은 마스크 밖”이라는 엄격한 조건에 미달합니다. 후처리에서 가방 영역 밖 하단은 원본을 복원했지만, 가방 자체가 덮는 픽셀은 남아 있습니다.
- 3배 정지 비교에서 벨트와 고리 연결이 명확하지 않고 손에 든 가방처럼 보일 수 있습니다. 가방 아래 모서리 잔여 픽셀, 팔 접합부 윤곽 차이도 남았습니다. Run 팔 변화는 있으나 다리와 반대 위상의 자연스러운 스윙 전체는 미달입니다. 시도 제한에 도달해 추가 생성하지 않았습니다.
- 전체 생성 결과에서 머리·몸 크기가 달라져도 마스크 밖 결과는 폐기했습니다. 원본 프레임 전체를 생성본으로 교체하지 않았습니다. Unity 적용/게임 내 재생 검증은 하지 않았습니다.
