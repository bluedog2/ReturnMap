# Re:Trap 배경 — Verification v2
2026-10-30. “디스토피아적인 느낌을 덜 내야 한다”는 피드백에 따라 Verification만 재제작했다. 승인된 Play Far/Near 및 Play 목업은 변경하지 않았다. 저장소 쓰기는 이 폴더 안에서만 수행했으며 git은 사용하지 않았다.

## 방향
살구·연분홍 노을과 온전한 빌딩, 따뜻한 창문, 사람이 사는 낡은 상가·주택. 옥상 물탱크·안테나·화분·빨랫줄·환기구·전선과 RE·왕관·X·별 낙서를 넣고 폐차·철골 잔해를 제외했다. Play의 직사각형 건물과 스카이라인 고점 리듬을 공유하지만 동일 건물을 정확히 복원한 장면은 아니다. 배경은 낮은 채도와 제한된 명암으로 정리해 청회색 타일과 따뜻한 색상 대비를 만든다. 배경에 적 진영 초록·보라는 없으며 크림슨도 이번에는 사용하지 않았다.

## 제작·시도 횟수
내장 image_gen 사용. Verification Far **2회**, Near **2회**, 각각 2차 채택. Far 1차는 팔레트 변환 후 구름 점무늬, Near 1차는 복잡한 표면 질감 때문에 재생성했다. Play는 이번에 생성하지 않았다(기존 Far 2회·Near 1회).

코드는 최근접 격자 복원·팔레트 정리·알파 이진화·가로 이음 맞춤·기존 리소스 합성·라벨에만 사용했다. 그림을 코드로 그리지 않았다. 알파는 128 기준으로 0/255, 고립된 양자화 색은 주변 다수색으로 정리했다. 원경에서 건물이 없는 상단 230행은 노을/구름 2색으로 정리했다. 디더·AA·연속 그라데이션을 추가하지 않았다.

좌우 끝 8열 색 정렬 후 팔레트 재매핑을 적용했다. 끝 열 RGBA 불일치 0, 파일당 24색 이하, 알파 0/255를 검사했다. 연결 시트의 중앙 x=1280이 이음 경계다. 목업·시트·생성 원본에는 단일 배경의 24색 제한을 적용하지 않는다.

## 한계
- Unity 임포트·실제 스크롤·패럴랙스는 검증하지 않았다.
- 끝 열은 일치하지만 640px 반복 주기와 경계 부근의 좁은 색 정렬 구간은 알아볼 수 있다.
- 가는 전선·소품에 생성 원본의 불균일한 픽셀 간격이 일부 남는다.
- 기존 목업 배치의 바닥 2줄이 근경 하단 낙서 일부를 가린다. 전체 낙서는 Near와 연결 시트에서 확인할 수 있다.
- 밝아진 노을의 최종 가독성은 실제 게임 화면에서 추가 확인이 필요하다.

Sources의 시도 원본은 재현·감사용 영구 기록이다. 임시 중간 이미지는 남기지 않았다. image_gen 원본은 허용된 $CODEX_HOME/generated_images/에도 유지된다. Sources/process.ps1 및 기존 validation.txt·palette_audit.txt는 v1 기록이다. 재현에는 process_v2.ps1, 최신 검증에는 validation_v2.txt를 사용한다.
