# Re:Trap 배경 재디자인 컨셉 v2

사용자 승인용 시안. 제작일 2026-10-30. 작업 파일은 이 디렉터리에만 저장했으며 기존 게임 리소스는 교체하지 않았다. git은 사용하지 않았다.

## 세트 설명

- **Play / 밤:** 남색 하늘과 탁한 자주 구름 아래 붕괴한 고층 건물, 꺼진 광고판, 작은 크림슨 경고등. 근경은 무너진 공장·철골·전선·담장·폐차와 희미한 RE / 왕관 / X / 별 낙서로 구성했다.
- **Verification / 흐린 황혼:** 같은 도시 구도를 회청색으로 밝히되, 빌드 타일보다 어둡고 차분하게 유지했다. 원경은 근경보다 평균 명도가 낮다.

## 제작과 시도 횟수

내장 **image_gen**으로 모든 배경 그림을 생성했다. 코드로 건물·전선·낙서 등의 그림을 그리지 않았다. 프롬프트는 `Sources/*_prompt.txt`에 보관했다.

| 레이어 | image_gen 호출 횟수 | 선택 |
|---|---:|---|
| Play Far | 2 | 1차의 미세 점무늬 때문에 평면 색면으로 재생성한 2차 |
| Play Near | 1 | 1차 |
| Verification Far | 1 | Play Far 1차를 참조하여 같은 도시의 황혼으로 편집 |
| Verification Near | 1 | Play Near를 참조하여 같은 도시의 황혼으로 편집 |

Far는 640×360의 2배 블록, Near는 640×256의 4배 블록을 요청했다. 생성기가 실제로 반환한 이미지 크기는 요청 배수와 다르므로 최종 규격으로 최근접 샘플링하고 제한 팔레트로 정리했다. Near 알파는 128 기준으로 0/255로 정리했다. 황혼 원경은 먼저 색을 정리한 뒤 RGB 밝기를 0.67배로 낮추고 최종 팔레트로 재매핑했다. 최종 출력에는 디더링을 추가하지 않았다.

가로 연결은 각 레이어 좌우 끝 8열에만 교차 색 정렬과 팔레트 재매핑을 적용했다. 맨 끝 열의 RGBA는 행별로 완전히 같다. 반복 시트를 직접 확인했다. `Sources/process.ps1`은 격자 복원·팔레트 정리·가로 경계 정렬·기존 리소스 합성·라벨만 수행한다.

## 한계

- 정지 화면 컨셉 승인용이다. Unity 임포트·실제 카메라 이동·패럴랙스 속도·화면 밝기 설정에 따른 런타임 검증은 하지 않았다.
- image_gen은 요청한 정수 배수 격자를 정확하게 보장하지 않는다. 최종 파일은 규격과 팔레트가 정규화되어 있지만 가는 전선·철골에는 생성 원본에서 유래한 픽셀 불규칙성이 남을 수 있다.
- 각 페이즈는 같은 도시 구도를 유지하지만 생성 편집 과정에서 작은 파손 윤곽은 완전히 일치하지 않는다.
- 크림슨 경쟁을 피하도록 정리하면서 근경 낙서는 거의 차콜로 남았다. 모크의 바닥 2줄은 폐차·하단 잔해 일부를 가린다. 전체 근경은 연결 시트에서 확인할 수 있다.
- 긴 수평 이동에서는 640px 단위 건물 배치의 반복을 알아볼 수 있다. 좌우 경계 픽셀의 연결과 별개인 반복 주기의 한계다.

임시 중간 파일은 남기지 않았다. `Sources`의 1차 원본은 시도 기록이며 임시 파일이 아니다. image_gen 기본 원본은 허용된 `$CODEX_HOME/generated_images/`에 유지된다.
