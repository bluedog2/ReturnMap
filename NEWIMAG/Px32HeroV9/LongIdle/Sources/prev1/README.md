## 승인 기준과 좌표

`Idle/Hero_Idle_8.png`의 실제 0번을 기준으로 했다. 별도 마스터의 가방 위치는 (53,95)이지만, 승인 Idle README와 Hit README에 명시된 시트 0번 위치는 이전 장 지연 때문에 **(51,95)**이다. 실제 PNG와 끊김 없이 연결하기 위해 BagOut F0와 BagIn F3은 Idle 0 그대로다. 승인 파일은 수정하지 않았다.

체인은 가방을 떼어도 **허리에 남는다**. R2_chain의 상단 6px를 (56,89)에 둔다. 가방은 Bag_Hip_ThreeQuarter, Bag_Held_ThreeQuarter, Bag_Held_Open 원본만 정수 평행이동했다. Hip_Open은 이번 동작에서 사용하지 않았다. 가방 본체 가림은 하지 않고, 손잡이만 장갑이 앞에서 덮는다. 사용한 가방 레이어와 손 가림 마스크를 별도로 저장했다.

원본 파일 크기는 Hip 18×16, Held 25×22, Held Open 28×30이다. 새로 그리거나 리샘플하여 크기를 맞추지 않았다. 따라서 원본 보존은 통과하지만 **일정한 크기 조건은 미통과**다. Open은 입 개방으로 높이뿐 아니라 폭도 커진다. 이를 전체 통과로 표시하지 않는다.

## 제작·복구와 생성 횟수

기존 build.py, compose.py, 생성 원본·블록·프롬프트·recovery를 먼저 읽었다. 기존 attempts.json은 키 포즈 4회 시점에 멈춰 있었으며 실제 긴 대기 원본은 12개였다. 이 12개를 재생성하지 않았다. 키 0·3·6·9의 기존 3배 합성본을 직접 확인한 후 기존 사이 장을 재사용했다. 이전 실행이 키를 실제로 열어봤는지는 파일만으로 증명하지 않으며, 이번에는 직접 확인했다.

BagOut F1은 generated1과 prompt2가 남아 있었다. 2회차 호출 완료 여부가 불명확하므로 보수적으로 사용한 1회로 포함했고, 이번 수정본은 generated3으로 저장했다. 원본 파일로 확인되는 누적 생성은 21회, 미확인 이전 1회를 포함한 예산 계산은 22회다.

그림 생성은 내장 image_gen만 사용했다. 최종 프롬프트는 Sources/*_prompt*.txt, 원본은 *_generated*.png, 복원본은 *_blocks*.png, 격자 정보는 *_recovery.json에 있다. 코드 처리는 정수 블록 중심 복원·승인 팔레트 매핑·알파 이진화·정수 이동·마스크 합성·조립·검증뿐이다. 확대는 픽셀 배열 정수 반복이다.

마스크는 팔 및 이동 전후 가방 위치, 가방 제거 복원 부위, 호흡 몸통 부분을 포함한다. 머리·얼굴·몸 방향·다리·신발은 Idle 0 보호 영역으로 남겼다. 가방 제거는 기존 Idle Body_patch를 재사용했다. LongIdle F2/3/4/8/9/10의 몸통 x65..84/y73..88은 승인 픽셀을 위로 1px 이동해 작은 호흡을 준다.

F5~7에서 손잡이가 충분히 가려지지 않던 문제를 수정했다. F4는 손과 가방을 왼쪽으로 옮겨 다음 장 연결을 보완했다. 마지막 11→0은 닫힌 입·같은 가방 좌표를 유지하며 팔 자세가 복귀한다. 변경 픽셀은 261개이며, 완전히 같은 프레임으로 반복을 멈추지는 않았다. 키 프레임의 재킷 접힘 변화는 여전히 눈에 띈다.
