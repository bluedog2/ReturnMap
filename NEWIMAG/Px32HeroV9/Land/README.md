## ASF ④와 미리보기

`tools/sprite/asf-to-px32.py`의 check/rules_for/sheet_spec만 호출했다. scale_frames(②)·place는 실행하지 않았다. 검사 실패 0. 규격표 Land 3→4장 차이는 예상 경고로 따로 기록했다. bbox 높이는 [74, 74, 93, 102]px. 원본 착지 웅크림에서 일어서기에 따른 변화이며 축소로 맞추지 않았다.
