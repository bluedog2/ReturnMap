# Re:Trap 최종 FX / 월드 UI / HUD — 1배 PNG

## 파일

- Effects/: Fx_Dash (32×32, 5), Fx_Hit (32×32, 4), Fx_Death (48×48, 6), Fx_Respawn (48×48, 6), Fx_Dust (16×16, 4), Fx_EnemyPoof (48×48, 6), GoalMarker (32×32, 4), Gauge_Ring24 (24×24, 9), Gauge_Ring32 (32×32, 9).
- UI/: Gauge_Ring24_Background (24×24), Gauge_Ring32_Background (32×32), Icon_Spike / Icon_ArrowShooter / Icon_DropHammer / Icon_Remove (각 32×32), Particle_Critical / Particle_Dud / Particle_Beneficial (각 8×8).
- Preview_4x.png: 최종 파일별 한 줄, 최근접 4배 표시. 링 두 종류는 지정 콘크리트 타일 위에도 표시.
- validation.json: 18개 게임용 PNG의 개별 검사와 전체 통과 여부.
- build.ps1 / verify.ps1: 재현용 제작·검사 스크립트. pixel_operations.txt: 프레임별 고립점 복사 횟수.

모든 게임용 PNG는 원래 셀 크기의 1배 RGBA, 가로 한 줄, 셀 간격 0이다. 시트는 왼쪽부터 프레임 순서이며 게이지는 0/8부터 8/8까지다.

## 출처와 보정

출처는 NEWIMAG/FxUiConceptV2/_1x/*.png의 승인된 컨셉 컷아웃이다. 원본 컨셉은 image_gen 제작물이지만 이번 최종화의 image_gen 호출은 **0회**다. 새 선·도형을 그리지 않고 원본 픽셀의 컷아웃, 평행이동, 복사와 요청된 링 색 보정을 사용했다.

- Ring24: 기존 링의 픽셀을 중심 방향으로 가로·세로·대각 대칭 복사하여 외곽 크기는 유지하고 안쪽 두께를 늘렸다. 테두리를 포함해 4px 이상 두께를 확보하며 축 방향 두께는 5px다. 채움은 #DC526B, #F18490, 팔레트의 흰색 계열 #F7EEE4, 테두리는 #19181F. 바탕은 #19181F / #3D3940 차콜이다. 12시부터 시계방향 45도씩 채운다.
- Ring32: 승인된 채움색과 실루엣을 유지했다. 중앙 지름 14px 공간을 검사했다. 두 게이지의 Background는 각각 0/8 프레임과 픽셀 단위로 동일하다.
- Dash: 오른쪽 달리기 기준으로 먼지의 오른쪽 끝을 x=30에 맞추고, 컨셉의 크림슨 속도선 픽셀을 왼쪽 x=1까지 반복 복사했다. 가까운 행은 건너뛰어 굵은 막대가 되지 않도록 했다. 셀은 32×32 그대로다.
- 파편: 8방향 이웃이 없는 1픽셀 점을 중심 쪽 옆 칸으로 복사하여 최소 2픽셀로 정리했다. 기존 덩어리와 실루엣은 유지했다.
- Dash / Respawn / Dust / GoalMarker: 매 프레임 최하단 불투명 픽셀이 셀 바닥 행에 닿는다. GoalMarker는 원본 깃대 가로 위치를 유지했다.
- 파티클: 8×8 셀을 유지하고 가장자리 픽셀을 컷아웃하여 1px 투명 여백을 확보했다. 따라서 원본의 가장 바깥 불티와 십자 끝 일부는 잘렸다. 확대나 재샘플링은 하지 않았다.

최종화 시도는 **4회**다. 1차 결과 확인 후 2차에서 대시의 인접 속도선 반복을 줄이고 깃대 가로 위치를 고정했다. 3차에서 링의 흰색 비중을 줄이고, 4차에서 상단의 기존 링 픽셀에만 흰 하이라이트를 배치했다.

## 검사

validation.json은 출력 PNG를 다시 읽어서 크기, 프레임 수, 불투명 색 수(16 이하), 팔레트 밖 픽셀, 알파 값, 순흑, 셀 가장자리, 프레임별 최하단 행, 고립 1픽셀 점, Ring32 중앙 공간, Background 일치를 검사한다. 색 수는 투명 픽셀을 제외한다.

Preview_4x.png는 사용자 지정 배경 #1A191F와 원본 콘크리트 타일을 쓰는 검토용 합성 이미지다. 게임용 PNG의 팔레트·16색·1배 제한은 적용하지 않는다. 미리보기 라벨은 설명용 텍스트이며 게임 리소스에는 포함되지 않는다.

## 한계

PNG와 정적 4배 미리보기까지 검사했다. Unity 임포트, 실제 게임에서의 재생 속도·피벗·캐릭터 이동 동기화는 검증하지 않았다. 원본 컨셉의 프레임별 덩어리 변화와 픽셀 계단은 유지했으며 애니메이션을 새로 그리지는 않았다. 임시 컴파일 파일은 정리했다. 저장소의 다른 경로와 게임 코드는 수정하지 않았고 git은 사용하지 않았다.
