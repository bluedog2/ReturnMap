# Re:Trap StylePilot2 — 생성 후보 및 실패 조건 기록

**완전 합격본이 아니다.** 크기마다 image_gen을 별도로 4회(총 12회) 호출했다. 정확한 블록 격자 요청은 지켜지지 않았으며, A/B는 목표 캐릭터 키도 충족하지 못했다. 최선의 비교용 후보를 지정된 파일명으로 저장했다. C는 키 조건만 충족한다. 세 후보 모두 깨끗한 단일 1px 외곽선을 보장하지 못하므로 바로 게임에 넣을 완성 리소스로 취급하지 않는다.

## 입력과 생성

- 직접 열어 확인한 스타일: `../StyleRef/ref_pixelstyle.webp`
- 직접 열어 확인한 디자인: `../StyleRef/ref_concept.webp`
- 직접 열어 확인한 품질 기준: `../StylePilot/imagegen_reference.png`
- 모든 image_gen 호출에 스타일/디자인 두 파일을 참조 입력으로 전달했다. A 1차에는 품질 기준도 전달했다.
- 내장 image_gen만 사용. 캐릭터 도형/선/픽셀을 코드로 그리거나 덧칠하지 않았다.
- 전체 프롬프트, 생성 순번과 자동 저장 원본 경로: `attempts.json`. 선택 원본은 `Sources/`에 바이트 그대로 복사했다.
- A 1~3차는 투명 배경, 나머지는 녹색 크로마 배경 요청. 모든 반환 원본은 **1254×1254**였다. 요청한 1024 또는 1056 출력과 달랐다.

## 선택 결과

bbox는 0부터 시작하는 `[left, top, right, bottom)` 좌표다. k는 원본의 경계 에너지에서 추정한 공통 가로/세로 주기이며 **정확한 격자가 검증된 값이 아니다**.

|크기|시도|선택|요청 k|추정 k|1배 캔버스|bbox|실제 폭×키|목표 키|
|---|---:|---:|---|---:|---|---|---|---|
|A|4|1차|16 (3차는 20/1280 요청)|19.6|64×64|[11,3,52,64)|41×61|48 — 미달|
|B|4|3차|11|13.5|96×96|[22,16,74,96)|52×80|68 — 미달|
|C|4|4차|8|12.0|128×128|[30,27,97,128)|67×101|100~110 — 충족|

- A: 후속 후보들은 더 굵은 블록을 보였지만 추정 격자 복원 키가 68~71px라 64px 캔버스에 들어가지 않았다. 추가 축소나 잘라내기 없이 캔버스에 들어가는 1차를 비교용으로 선택했다. 작은 얼굴 표현과 외곽선은 불충분하다.
- B: 3차는 2차(95px)보다 키가 작고 장식과 실루엣이 단순하다. 1/4차는 복원 키가 캔버스를 초과했다. 선택본도 68px 목표에는 실패했다.
- C: 4차는 101px로 목표 범위에 들고, 3차(93px)보다 목표 밀도에 가깝다. 1/2차는 세밀한 경계 때문에 복원 크기가 캔버스를 초과했다. 선택본도 불규칙한 원본 경계로 인해 내부 점과 외곽선 단절이 남아 있다.

## 후처리

`process.py`: PNG 디코딩 → 강한 경계의 주기/위상 탐색 → 같은 k의 정사각 격자 중앙 한 점 샘플 → 기존 팔레트의 RGB 유클리드 최근접 색 → 알파 0/255 → 투명 여백 제거 → 원래 크기 그대로 중앙/하단 배치.

모드/평균 필터, 외곽선 보강, 모폴로지, 손으로 칠하기, 목표 키에 맞춘 추가 리사이즈를 사용하지 않았다. 원본이 정규 격자가 아니므로 중앙 샘플은 근사 복원이며 무손실 역확대가 아니다. 정확한 native pixel art 복원에 성공했다고 주장하지 않는다. 완성된 C를 A/B로 축소하지 않았고 각 크기에는 독립 생성 원본을 사용했다.

분리된 알파 연결 요소가 1~2px인 경우만 제거할 수 있게 제한했다. 이번 모든 후보에서 실제 제거는 0px. 연결된 내부 잡점은 임의로 수정하지 않았다. `grid_report.json`에 모든 시도의 측정값을 기록했다. 격자 점수는 비교 지표이며 합격 판정 확률이 아니다.

## 검사와 한계

- A/B/C 불투명 픽셀의 팔레트 밖 색: 각각 **0**. 팔레트 추가색: **없음(0색)**. 기존 20색 그대로 사용하며 각 후보는 20색 사용.
- A/B/C 알파 집합: 각각 **{0,255}**. 투명 픽셀 RGB는 0. 팔레트 검사는 불투명 픽셀에 적용한다.
- 각 발바닥: 캔버스 마지막 행. 가로 중앙 오차 A/C -0.5px, B 0px. 홀수 폭 bbox와 짝수 캔버스 때문에 생기는 최소 정수 좌표 차이다.
- 6배/3배 출력은 픽셀 복제 방식이다. 비교/화면의 원본 바닥·기존 캐릭터에는 주인공 20색 팔레트를 강제하지 않았다.
- **남은 실패:** A/B 키 불일치, 원본의 균일 격자 미준수, 1px 외곽선 단절과 미세 디테일, 엄밀한 2.5등신과 자세 통일 미보장. 최대 생성 횟수에 도달하여 추가 생성하지 않았다. 기존의 코드 드로잉 방식으로 이를 메우지 않았다.
- 저장소 쓰기는 `NEWIMAG/StylePilot2/`에만 수행. git을 사용하지 않았다. image_gen 자동 원본은 허용된 `$CODEX_HOME/generated_images`에 보존했다. 설치 시도는 네트워크 제한으로 실패하여 외부 Python 패키지를 사용하지 않았다.
