# 3칸 기준 비율 체계 (2026-10-30 사용자 결정)

플레이테스트 피드백: "캐릭터에 비해 맵이 작고 점프가 굼뜸, 함정이 작아 보임, 플레이 카메라가 너무 확대·맵 밖으로 나감".
사용자: **캐릭터는 줄이지 않는다**(작으면 뭉개져서 키운 것) — 조금 더 키워도 되니 **전체를 딱 떨어지는 비율로**.
늘어나는 픽셀은 **확대가 아니라 디테일로** 채운다(새로 그리기).

## 기준
- 1칸 = 32px = 1 월드 유닛 (PPU 32, 타일·배경·이펙트·UI 32px 체계 유지)
- **주인공 = 정확히 3칸 (96px)** — 모든 크기를 칸 정수배로

## 디테일 원칙 (늘어난 픽셀 활용)
- 기존 그림을 늘리지 않는다(뭉개짐). 승인 디자인을 참조로 **목표 크기에서 새로 그린다**.
- 늘어난 픽셀은 얼굴(눈·표정), 머리카락 결, 옷 주름·재봉선, 장비 부품, 금속 하이라이트에 쓴다.
- 음영 2~3단 → 3~4단, 캐릭터 색 수 상한 20 → 24. 외곽선 1px 유지.
- 함정은 64px로 4배 넓어진 면적에 볼트·용접선·경고 문구·상태별 디테일(녹 번짐·열기 균열·금 장식)을 넣는다.
