# 주인공 애니메이션 V6 — 허리춤 가방 + 전환 동작 (2026-11-06 사용자 결정)

## 결정
- 이빨 달린 가방은 **평소엔 허리춤**(벨트 옆, 오른쪽을 볼 때 카메라 쪽 엉덩이 옆·손 아래)에 매달려 있다. 지금처럼 몸 앞을 가리지 않는다.
- **오래 서 있을 때만** 가방을 꺼내 앞으로 든다(긴 대기). 꺼내고 넣는 **전환 동작**이 있다.
- 다른 상태 사이에도 필요한 곳에 전환 동작을 넣는다.

목적: 동작이 잘 읽히게(팔·앞모습이 보임), GPT 가 프레임마다 가방 크기·모양을 바꾸던 실패(V3~V5)를 줄이기, 가방은 긴 대기의 재미 요소로 살리기.

## 상태·전환 표

| 상태/전환 | 프레임 @fps | 들어가는 조건 | 끊기면 |
|---|---|---|---|
| Idle (허리춤 가방) | 6 @8 루프 | 기본 | — |
| **Idle → 긴대기: 가방 꺼내기** | 4 @10 | 입력 없이 서 있기 6초 | 입력 즉시 해당 상태로 |
| **긴대기** (가방 들고 이빨 딱딱) | 6 @8 루프 | 꺼내기 끝 | 입력 → 넣기 또는 즉시 전환 |
| **긴대기 → Idle: 가방 넣기** | 3 @12 | 이동 외 입력(점프 제외)·시간 | 이동·점프·대시는 넣기 생략, 바로 전환 |
| **출발** (Idle → Run) | 2 @15 | 서 있다가 이동 입력 | 0.13초 — 조작은 즉시, 그림만 |
| Run | 8 @18 루프 | — | — |
| **멈춤** (Run → Idle 브레이크) | 3 @15 | 달리다 입력 놓음(지면) | 이동 입력 → Run |
| **방향 전환** (턴) | 2 @15 | 달리는 중 반대 방향 입력 | 끝나면 Run |
| JumpStart · Fall · Land · Dash · Hit · Death | 지금 규격 | — | — |

원칙: **전환 동작은 그림만 — 조작은 절대 늦추지 않는다.** 이동·점프·대시 입력이 오면 전환 중이라도 바로 해당 동작으로 끊는다(긴대기 → 가방 넣기는 생략하고 가방은 허리춤 그림으로 바로 바뀜).

## 단계
1. **시험**: Idle(6) · Run(8) 을 허리춤 가방으로 GPT 생성 → 머리는 지금 승인 Idle 머리 합성, 몸 크기는 지금 Idle 과 같게. 여기서 실패하면 전체 계획을 다시 판단.
2. 나머지 동작(JumpStart·Fall·Land·Dash·Hit·Death) 허리춤 가방으로 다시 그리기.
3. 전환 동작 그리기: 꺼내기 4 · 긴대기 6 · 넣기 3 · 출발 2 · 멈춤 3 · 턴 2.
4. FSM 상태 추가(`PlayerAnimationFSM`) + 컨트롤러·클립(`Lord_Controller`) + 규격(`Px32Rules`·`Px32HeroWiring`·`SpriteClipRebinder`).
5. CI · 재생 프로브(상태별 실제 재생 프레임) · 스모크.
